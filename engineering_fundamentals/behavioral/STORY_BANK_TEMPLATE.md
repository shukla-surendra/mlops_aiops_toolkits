# Story Bank Template

Fill this in with your own incidents — see `README.md` for the STAR(L) framework and the
LP/competency map to sort against. Aim for 8-12 rows; each real story should end up tagged
against 2-3 different LPs/competencies, since that's what makes a compact bank cover a
full loop.

## How to fill this out

1. Copy the row template below once per raw incident from your brain-dump.
2. Write Situation/Task/Action/Result/Learning in your own words, in the first person,
   as if speaking it — not as bullet fragments. If a sentence doesn't sound like something
   you'd actually say out loud, rewrite it.
3. Force a number into Result even if approximate.
4. Tag every LP/competency this story could honestly answer — don't force a fit; an
   honest 2-tag story beats a stretched 5-tag one that falls apart under a follow-up.
5. Time yourself telling it out loud. Target: 90 seconds–2 minutes. Note the actual time
   in the row so you know which stories need trimming.

## Coverage checklist

Once your bank is populated, sanity-check coverage — every row above should let you check
at least one box in each column without stretching:

| Category | Covered by which story titles? |
|---|---|
| A time you disagreed with someone senior | |
| A time you failed / made a mistake | |
| A time you dealt with ambiguity | |
| A time you influenced without authority | |
| A time you mentored/developed someone | |
| A time you delivered under a hard deadline | |
| A time you simplified something | |
| A time you changed your mind based on new evidence | |
| Your proudest technical decision | |
| A time you said no / pushed back on scope | |
| A time you gave tough/direct feedback (candor culture) | |
| A time you received tough feedback and changed your behavior (candor culture) | |
| A time you refused to accept "good enough" on craft/detail (craft & discretion) | |
| A time you owned something with no clear owner (writing culture — extreme ownership) | |
| A time you caught a subtle correctness/trust issue before it hit users (writing culture) | |
| A time you shipped a smaller version deliberately instead of waiting (writing culture — urgency) | |

If any row is empty after you've populated your bank, that's a gap — go back to the
brain-dump step and look specifically for an incident that fills it, rather than
stretching an existing story to cover it unconvincingly.
